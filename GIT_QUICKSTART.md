# Wildlife Monitoring AI - Git Quick Start

## If Git Command Works

If `git --version` works in your terminal, run these commands:

```bash
# Navigate to project
cd C:\Users\SHIVANI\.gemini\antigravity\scratch\wildlife-monitoring-ai

# Configure Git (one time only)
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# Initialize repository
git init
git add .
git commit -m "Initial commit - Wildlife Monitoring AI System"

# Create repository on GitHub, then:
git remote add origin https://github.com/YOUR-USERNAME/wildlife-monitoring-ai.git
git branch -M main
git push -u origin main
```

## If Using GitHub Desktop

Since you have GitHub installed, you likely have GitHub Desktop:

1. **Open GitHub Desktop application**
2. **File** → **Add Local Repository**
3. **Choose** `C:\Users\SHIVANI\.gemini\antigravity\scratch\wildlife-monitoring-ai`
4. If prompted "This directory does not appear to be a Git repository":
   - Click **"create a repository"**
5. **Publish repository** button (top right)
6. **Choose name**: `wildlife-monitoring-ai`
7. **Keep code private** or make **Public** (for portfolio)
8. Click **"Publish repository"**

Done! Your code is on GitHub! 🎉
